## Descripción

Este repositorio recopila las prácticas, laboratorios, programas y documentos elaborados durante el curso de **Ingeniería de Software** en la Universidad de Málaga. Está organizado por asignaturas, y sirve tanto como bitácora personal del estudiante como recurso para consulta futura.

## Asignaturas y contenidos

Las asignaturas incluidas son:

1. Modelado y Diseño de Software
   - Práctica 1 - Diagramas de clase con USE
   - Práctica 2 - Diagramas de clase con USE + Invariantes OCL
2. Ingeniería de Sistemas Intensivos en Datos
   - Lab 3 - Sistema de clasificación deportiva(redys)
   - Lab 5 - Pymongo
   - Lab 6 - TechWorld(mongo)  
3. Desarrollo de Software Crítica
   - Práctica 1 - Detección de Anomalías con Machine Learning
4. Aprendizaje Automático
   - Práctica 1 - Librerías de Python + Breast Cancer Wisconsin Dianostic(dataset)

## Cómo usar este repositorio

1. Clona el repositorio:

   ```bash
   git clone https://github.com/darchery/Cuaderno-Bitacora-de-Ingenieria-Software.git
   ```
2. Navega a la carpeta de la asignatura/práctica que te interese.
3. Consulta el código, los datasets y la documentación incluida (por ejemplo, archivos `.ipynb`, `.py`, diagramas, etc.).
4. Si vas a reutilizar o adaptar el contenido, asegúrate de revisar los comentarios, licencias y notas de autoria.
