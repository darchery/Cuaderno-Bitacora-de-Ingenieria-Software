Ejercicio 3:

Características principales de HTML

Versiones de HTML

  1. HTML 1.0/2.0 (1991-1995): Primeras versiones básicas, enfocadas en texto y enlaces. El 2.0 fue el primer estándar oficial.
  2. HTML 3.2 (1997): Introdujo mejoras como tablas, applets de Java y texto alrededor de imágenes.
  3. HTML 4.01 (1999): Versión estable que introdujo la separación de contenido y estilo mediante CSS, siendo muy popular durante años.
  4. XHTML 1.0 (2000): Una versión de HTML basada en XML, con reglas sintácticas mucho más estrictas.
  5. HTML5 (2014-actualidad): La versión actual, diseñada para aplicaciones web modernas. Incorpora video/audio nativo, Canvas, geolocalización y etiquetas semánticas.
  6. HTML Living Standard: Actualmente, HTML no se lanza por números enteros (como 6.0), sino que es una especificación viva (actualizada continuamente por el WHATWG).

Ventajas de HTML

  • Fácil de aprender y usar: Tiene una sintaxis sencilla, ideal para principiantes en el desarrollo web.
  • Compatibilidad universal: Funciona nativamente en todos los navegadores web (Chrome, Firefox, Safari, Edge, etc.) y plataformas.
  • Gratuito y estándar abierto: No requiere licencias ni software especial, siendo mantenido por el W3C.
