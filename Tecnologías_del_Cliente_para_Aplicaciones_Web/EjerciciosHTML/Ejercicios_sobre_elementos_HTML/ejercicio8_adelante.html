Historia de HTML

HTML(Hipertex Markup Language) es un lenguaje de etiquetas que define el contenido y la estructura de las páginas web. Creado por Tim Berners-Lee.

Características principales de HTML

Ventajas de HTML

Fácil de aprender y usar:
Tiene una sintaxis sencilla, ideal para principiantes en el desarrollo web.
Compatibilidad universal:
Funciona nativamente en todos los navegadores web (Chrome, Firefox, Safari, Edge, etc.) y plataformas.
Gratuito y estándar abierto:
No requiere licencias ni software especial, siendo mantenido por el W3C.

Versiones de HTML

HTML 1.0/2.0 (1991-1995):
Primeras versiones básicas, enfocadas en texto y enlaces. El 2.0 fue el primer estándar oficial.
HTML 3.2 (1997):
Introdujo mejoras como tablas, applets de Java y texto alrededor de imágenes.
HTML 4.01 (1999):
Versión estable que introdujo la separación de contenido y estilo mediante CSS, siendo muy popular durante años.
XHTML 1.0 (2000):
Una versión de HTML basada en XML, con reglas sintácticas mucho más estrictas.
HTML5 (2014-actualidad):
La versión actual, diseñada para aplicaciones web modernas. Incorpora video/audio nativo, Canvas, geolocalización y etiquetas semánticas.
HTML Living Standard:
Actualmente, HTML no se lanza por números enteros (como 6.0), sino que es una especificación viva (actualizada continuamente por el WHATWG).
